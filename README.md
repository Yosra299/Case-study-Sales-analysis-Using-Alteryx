# Alteryx Fundamentals Case Study

## Overview

This repository contains my solution for an Alteryx hands-on case study involving **DC Industries**, a fictional retail department store operating across multiple regions in the United States.

The objective was to prepare, cleanse, transform, and analyze customer and order data to answer several business questions and create a master dataset suitable for downstream reporting and visualization.

---

## Business Questions

The workflow was designed to answer the following questions:

- What were the top 25 most profitable orders?
- What day of the week was most profitable?
- How did profits vary by category and region?
- Which sub-categories contributed the most profit within each category?

Additionally, an export-ready dataset was created for use in external visualization platforms.
